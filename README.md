# 📚 holbertonschool-higher_level_programming

This repository gathers my Holberton School higher-level programming projects. Most directories focus on Python 3 fundamentals and object-oriented programming, with additional work in SQL, JavaScript, REST APIs, and server-side rendering.

## Projects

| Directory | Main topics |
|-----------|-------------|
| [`python-hello_world`](python-hello_world/) | Printing, strings, and first Python scripts |
| [`python-if_else_loops_functions`](python-if_else_loops_functions/) | Conditions, loops, and basic functions |
| [`python-import_modules`](python-import_modules/) | Imports, modules, and command-line arguments |
| [`python-data_structures`](python-data_structures/) | Lists, tuples, indexing, and iteration |
| [`python-more_data_structures`](python-more_data_structures/) | Sets, dictionaries, lambdas, and mapping |
| [`python-exceptions`](python-exceptions/) | Error handling and custom exceptions |
| [`python-classes`](python-classes/) | First classes and properties with `Square` |
| [`python-more_classes`](python-more_classes/) | Advanced class behavior with `Rectangle` |
| [`python-inheritance`](python-inheritance/) | Inheritance, type checks, and geometry classes |
| [`python-input_output`](python-input_output/) | File handling and JSON serialization |
| [`python-test_driven_development`](python-test_driven_development/) | Validation, doctests, and unit testing |
| [`python-object_relational_mapping`](python-object_relational_mapping/) | MySQL access with `MySQLdb` and SQLAlchemy |
| [`python-serialization`](python-serialization/) | JSON, Pickle, CSV, and XML serialization |
| [`python-abc`](python-abc/) | Abstract base classes, duck typing, and mixins |
| [`SQL_introduction`](SQL_introduction/) | Core MySQL queries and table management |
| [`SQL_more_queries`](SQL_more_queries/) | Users, privileges, joins, and relational queries |
| [`javascript-warm_up`](javascript-warm_up/) | Node.js basics and command-line scripting |
| [`javascript-dom_manipulation`](javascript-dom_manipulation/) | DOM updates, events, and fetch requests |
| [`restful-api`](restful-api/) | HTTP requests, Flask APIs, and authentication |
| [`python-server_side_rendering`](python-server_side_rendering/) | Flask templates and server-side rendering |

## Running the exercises

```bash
python3 <script>.py
node <script>.js
mysql -u <user> -p <database> < script.sql
```

## Notes

- Python scripts target `python3`.
- SQL projects are written for MySQL.
- JavaScript exercises use Node.js or the browser, depending on the directory.
- Flask-based projects may require installing external packages in a virtual environment.
