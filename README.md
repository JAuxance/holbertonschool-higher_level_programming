# 📚 holbertonschool-higher_level_programming

Holberton School — Higher Level Programming track.
All projects are written in **Python 3** (and SQL for the database exercises).

## Projects

| Directory | Topics |
|-----------|--------|
| [`python-hello_world`](python-hello_world/) | Printing, string formatting, basic I/O |
| [`python-if_else_loops_functions`](python-if_else_loops_functions/) | Conditionals, loops, functions |
| [`python-import_modules`](python-import_modules/) | Modules, imports, command-line arguments |
| [`python-data_structures`](python-data_structures/) | Lists, tuples, indexing, iteration |
| [`python-more_data_structures`](python-more_data_structures/) | Sets, dictionaries, `map`, `lambda` |
| [`python-exceptions`](python-exceptions/) | Exception handling (`try/except/finally`, raising) |
| [`python-classes`](python-classes/) | OOP — `Square` class, properties, validation |
| [`python-more_classes`](python-more_classes/) | OOP — `Rectangle`, `__str__`, `__repr__`, `__del__`, class methods |
| [`python-inheritance`](python-inheritance/) | Inheritance, `isinstance`, `issubclass`, geometry classes |
| [`python-input_output`](python-input_output/) | File I/O, JSON serialization, `Student` class |
| [`python-serialization`](python-serialization/) | JSON, Pickle, CSV, XML serialization |
| [`python-abc`](python-abc/) | Abstract classes, duck typing, multiple inheritance, mixins |
| [`SQL_introduction`](SQL_introduction/) | MySQL basics, `INFORMATION_SCHEMA`, queries |

## Setup

```bash
# Create and activate the virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

## Conventions

- Python scripts follow **PEP 8**.
- All scripts include a `#!/usr/bin/python3` shebang.
- Run any script with: `python3 <filename>.py`
