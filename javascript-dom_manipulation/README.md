# javascript-dom_manipulation

JavaScript exercises about selecting DOM elements, reacting to user events, and fetching remote data.

## Files

| File | Description |
|------|-------------|
| `0-script.js` | Change the header text color to red |
| `1-script.js` | Change the header color using `querySelector` |
| `2-script.js` | Add the `red` class to the header |
| `3-script.js` | Toggle the header class between red and green |
| `4-script.js` | Add a new `<li>` item to the list |
| `5-script.js` | Update the header text when clicking a button |
| `6-script.js` | Fetch and display a Star Wars character name |
| `7-script.js` | Fetch and list Star Wars film titles |
| `8-script.js` | Fetch and display the French translation of "hello" |

## Demo Files

Each script has a matching `*-main.html` file you can open in a browser to test the behavior.

## Run

Open one of the HTML files in your browser, for example:

```bash
xdg-open 8-main.html
```

## Topics

- DOM selection
- class manipulation
- event listeners
- `fetch()` and JSON
