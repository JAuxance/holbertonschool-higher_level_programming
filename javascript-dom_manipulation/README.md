# 📂 javascript-dom_manipulation

This project practices client-side JavaScript in the browser. The exercises manipulate the DOM, react to user events, update classes and text content, and fetch data from external APIs.

## Files

| File | Description |
|------|-------------|
| `0-script.js` | Change the text color of the header |
| `1-script.js` | Change the header color on click |
| `2-script.js` | Add a CSS class to the header on click |
| `3-script.js` | Toggle the header class between red and green |
| `4-script.js` | Add a new list item to the page |
| `5-script.js` | Update the header text |
| `6-script.js` | Fetch and display a Star Wars character |
| `7-script.js` | Fetch and list Star Wars movie titles |
| `8-script.js` | Fetch and display a translated greeting |
| `0-main.html` to `8-main.html` | Demo pages used to test each script |

## Running the exercises

Open the matching `*-main.html` file in a browser and load the corresponding script.
