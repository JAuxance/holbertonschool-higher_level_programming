# 📂 javascript-warm_up

This project introduces JavaScript with small Node.js command-line scripts. The exercises cover output, argument handling, type conversion, loops, recursion, and simple arithmetic functions.

## Files

| File | Description |
|------|-------------|
| `0-javascript_is_amazing.js` | Print a first JavaScript message |
| `1-multi_languages.js` | Print multiple lines |
| `2-arguments.js` | Report how many arguments were passed |
| `3-value_argument.js` | Print the first argument or a fallback message |
| `4-concat.js` | Print two arguments in a sentence |
| `5-to_integer.js` | Convert an argument to an integer |
| `6-multi_languages_loop.js` | Print lines from an array with a loop |
| `7-multi_c.js` | Print `C is fun` a given number of times |
| `8-square.js` | Print a square made of `X` characters |
| `9-add.js` | Add two integers |
| `10-factorial.js` | Compute a factorial recursively |
| `11-second_biggest.js` | Find the second largest integer from the arguments |

## Running a script

```bash
node <filename>.js
```
