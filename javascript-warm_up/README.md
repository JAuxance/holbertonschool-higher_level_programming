# javascript-warm_up

Introductory Node.js exercises about variables, command-line arguments, loops, functions, and basic arithmetic.

## Files

| File | Description |
|------|-------------|
| `0-javascript_is_amazing.js` | Print a simple string |
| `1-multi_languages.js` | Print multiple lines |
| `2-arguments.js` | Display the number of provided arguments |
| `3-value_argument.js` | Print the first argument passed to the script |
| `4-concat.js` | Concatenate two arguments into a sentence |
| `5-to_integer.js` | Convert an argument to an integer |
| `6-multi_languages_loop.js` | Print multiple lines from an array |
| `7-multi_c.js` | Print `C is fun` a given number of times |
| `8-square.js` | Print a square using `X` |
| `9-add.js` | Add two integers |
| `10-factorial.js` | Compute the factorial of a number |
| `11-second_biggest.js` | Find the second biggest integer in the arguments |

## Run

```bash
node 0-javascript_is_amazing.js
node 11-second_biggest.js 1 4 2 9
```

## Topics

- Node.js basics
- `process.argv`
- loops and conditionals
- functions and recursion
