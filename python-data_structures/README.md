# 📂 python-data_structures

This project focuses on Python lists and tuples. The exercises cover indexing, replacement, iteration, string cleanup, matrix printing, and simple tuple operations.

## Files

| File | Description |
|------|-------------|
| `0-print_list_integer.py` | Print each integer from a list |
| `1-element_at.py` | Return the element at a given index |
| `2-replace_in_list.py` | Replace an item in a list |
| `3-print_reversed_list_integer.py` | Print a list of integers in reverse order |
| `4-new_in_list.py` | Replace an item without mutating the original list |
| `5-no_c.py` | Remove all `c` and `C` characters from a string |
| `6-print_matrix_integer.py` | Print a matrix of integers |
| `7-add_tuple.py` | Add the first two elements of two tuples |
| `8-multiple_returns.py` | Return a tuple with string length and first character |
| `9-max_integer.py` | Find the largest integer in a list |
| `10-divisible_by_2.py` | Mark multiples of `2` in a list |
| `11-delete_at.py` | Delete an element at a given position |
| `12-switch.py` | Swap the values of two variables |

## Running a script

```bash
python3 <filename>.py
```
