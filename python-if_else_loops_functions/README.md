# 📂 python-if_else_loops_functions

Repository of Python exercises focused on conditionals, loops, and functions. Educational goal: learn fundamentals and adopt good practices for writing clear, correct Python scripts.

## Contents
- `0-positive_or_negative.py`: Simple example to determine whether an integer is positive, negative, or zero.

## Usage
- Run a script: `python3 <filename>.py`.
- Use the shebang `#!/usr/bin/python3` if the script should be executable directly.

## Conventions
- Style: follow PEP8 where possible.
- Scripts: prefer reusable functions and clear error messages.
- Permissions: some files may require `chmod +x` to be executable.
