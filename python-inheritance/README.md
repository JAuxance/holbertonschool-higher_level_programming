# 📂 python-inheritance

Python exercises focused on inheritance: class hierarchy, `isinstance`, `issubclass`, `type`, geometry classes, and method overriding.

## Files

| File | Description |
|------|-------------|
| `0-lookup.py` | Return the list of available attributes/methods of an object |
| `1-my_list.py` | `MyList` inheriting from `list` with a `print_sorted()` method |
| `2-is_same_class.py` | Check if an object is exactly an instance of a specified class |
| `3-is_kind_of_class.py` | Check if an object is an instance of, or inherited from, a class |
| `4-inherits_from.py` | Check if an object is an instance of a class that inherited from another |
| `5-base_geometry.py` | Empty class `BaseGeometry` |
| `6-base_geometry.py` | `BaseGeometry` with an `area()` method that raises an exception |
| `7-base_geometry.py` | `BaseGeometry` with `area()` and `integer_validator()` |
| `8-rectangle.py` | `Rectangle` inheriting from `BaseGeometry` |
| `9-rectangle.py` | `Rectangle` with `area()` and `__str__` |
| `10-square.py` | `Square` inheriting from `Rectangle` |
| `11-square.py` | `Square` with a custom `__str__` method |

## Usage

```bash
python3 <filename>.py
```
