# 📂 python-inheritance

This project focuses on inheritance, type inspection, and method reuse in Python. The exercises move from simple type checks to a small geometry hierarchy built with `BaseGeometry`, `Rectangle`, and `Square`.

## Files

| File | Description |
|------|-------------|
| `0-lookup.py` | List the available attributes and methods of an object |
| `1-my_list.py` | Extend `list` with a `print_sorted()` method |
| `2-is_same_class.py` | Check whether an object is exactly an instance of a class |
| `3-is_kind_of_class.py` | Check whether an object is an instance of a class or subclass |
| `4-inherits_from.py` | Check whether an object inherits from a class |
| `5-base_geometry.py` | Define an empty `BaseGeometry` class |
| `6-base_geometry.py` | Add an `area()` method that raises an exception |
| `7-base_geometry.py` | Add `integer_validator()` to `BaseGeometry` |
| `8-rectangle.py` | Create `Rectangle` from `BaseGeometry` |
| `9-rectangle.py` | Add `area()` and `__str__()` to `Rectangle` |
| `10-square.py` | Create `Square` from `Rectangle` |
| `11-square.py` | Customize the string representation of `Square` |

## Running a script

```bash
python3 <filename>.py
```
