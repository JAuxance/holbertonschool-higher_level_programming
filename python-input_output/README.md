# 📂 python-input_output

Python exercises focused on file I/O, JSON serialization/deserialization, and class-to-JSON conversion.

## Files

| File | Description |
|------|-------------|
| `0-read_file.py` | Read and print the content of a text file (UTF-8) |
| `1-write_file.py` | Write a string to a text file and return the number of characters |
| `2-append_write.py` | Append a string to a text file and return the number of characters |
| `3-to_json_string.py` | Return the JSON representation of an object (string) |
| `4-from_json_string.py` | Return the Python object represented by a JSON string |
| `5-save_to_json_file.py` | Save an object to a JSON file |
| `6-load_from_json_file.py` | Load a Python object from a JSON file |
| `7-add_item.py` | Add command-line arguments to a list stored in a JSON file |
| `8-class_to_json.py` | Return a dict description of an object for JSON serialization |
| `9-student.py` | `Student` class with a `to_json()` method |
| `10-student.py` | `Student` with filtered attribute export via `to_json(attrs)` |
| `11-student.py` | `Student` with `reload_from_json()` to restore from a dict |
| `12-pascal_triangle.py` | Return Pascal’s triangle as a list of lists |

## Usage

```bash
python3 <filename>.py
```
