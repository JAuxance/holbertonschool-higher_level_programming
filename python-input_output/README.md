# 📂 python-input_output

This project covers file handling and JSON serialization in Python. The exercises move from reading and writing text files to serializing objects and rebuilding class instances from dictionaries.

## Files

| File | Description |
|------|-------------|
| `0-read_file.py` | Read and print a UTF-8 text file |
| `1-write_file.py` | Write text to a file and return the character count |
| `2-append_write.py` | Append text to a file |
| `3-to_json_string.py` | Convert a Python object to a JSON string |
| `4-from_json_string.py` | Convert a JSON string back to a Python object |
| `5-save_to_json_file.py` | Save a Python object to a JSON file |
| `6-load_from_json_file.py` | Load a Python object from a JSON file |
| `7-add_item.py` | Store command-line arguments in a JSON list |
| `8-class_to_json.py` | Return a serializable dictionary for an object |
| `9-student.py` | Create a `Student` class with `to_json()` |
| `10-student.py` | Filter exported student attributes |
| `11-student.py` | Reload a student instance from a dictionary |
| `12-pascal_triangle.py` | Build Pascal's triangle |
| `test.py` | Local helper or experimentation script |

## Running a script

```bash
python3 <filename>.py
```
