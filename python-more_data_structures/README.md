# 📂 python-more_data_structures

This project extends the work on Python collections with sets, dictionaries, lambdas, and higher-order functions. The exercises focus on transforming, filtering, and combining data structures cleanly.

## Files

| File | Description |
|------|-------------|
| `0-square_matrix_simple.py` | Return a new matrix with squared values |
| `1-search_replace.py` | Replace matching values in a copied list |
| `2-uniq_add.py` | Sum all unique integers from a list |
| `3-common_elements.py` | Return the common elements of two sets |
| `4-only_diff_elements.py` | Return elements present in only one set |
| `5-number_keys.py` | Count the keys in a dictionary |
| `6-print_sorted_dictionary.py` | Print a dictionary sorted by key |
| `7-update_dictionary.py` | Update or insert a dictionary entry |
| `8-simple_delete.py` | Delete a key from a dictionary |
| `9-multiply_by_2.py` | Multiply all dictionary values by `2` |
| `10-best_score.py` | Return the key with the highest value |
| `11-multiply_list_map.py` | Multiply a list using `map` |
| `12-roman_to_int.py` | Convert a Roman numeral to an integer |

## Running a script

```bash
python3 <filename>.py
```
