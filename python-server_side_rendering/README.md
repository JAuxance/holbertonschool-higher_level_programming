# 📂 python-server_side_rendering

This project focuses on server-side rendering with Flask and Jinja. It combines reusable HTML templates, JSON-backed pages, and a dedicated application package that progressively adds dynamic data sources.

## Structure

| Path | Description |
|------|-------------|
| `templates/header.html` | Shared page header |
| `templates/footer.html` | Shared page footer |
| `templates/index.html` | Home page template |
| `templates/about.html` | About page template |
| `templates/contact.html` | Contact page template |
| `templates/items.html` | Items listing template |
| `templates/items.json` | Sample data for the items page |
| `python-server_side_rendering/` | Application package with the rendering tasks |

## Running the Flask tasks

```bash
python3 python-server_side_rendering/task_01_jinja.py
python3 python-server_side_rendering/task_02_logic.py
python3 python-server_side_rendering/task_03_files.py
python3 python-server_side_rendering/task_04_db.py
```
