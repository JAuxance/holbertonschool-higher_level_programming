# python-server_side_rendering

Flask and templating exercises about server-side rendering, dynamic pages, and reusable HTML templates.

## Structure

| Path | Description |
|------|-------------|
| `templates/` | Shared Jinja templates for the Flask pages |
| `python-server_side_rendering/` | Python exercises and data files for the project |

## Shared Templates

- `index.html`
- `about.html`
- `contact.html`
- `items.html`
- `header.html`
- `footer.html`
- `items.json`

## Main Topics

- Flask routing
- Jinja rendering
- template reuse with includes
- displaying data from JSON, CSV, and SQLite
