# 📂 python-server_side_rendering/python-server_side_rendering

This subdirectory contains the Python scripts used for the server-side rendering project. The tasks move from plain text template generation to Flask pages powered by JSON, CSV, and SQLite data sources.

## Files

| File | Description |
|------|-------------|
| `task_00_intro.py` | Generate invitation files from a template and attendee data |
| `task_01_jinja.py` | Render static pages with Flask and Jinja |
| `task_02_logic.py` | Render an items page from a JSON file |
| `task_03_files.py` | Display products loaded from JSON or CSV |
| `task_04_db.py` | Display products loaded from JSON, CSV, or SQLite |
| `template.txt` | Source template for invitation generation |
| `product_display.html` | HTML template used to render products |
| `products.json` | JSON product data |
| `products.csv` | CSV product data |
| `products.db` | SQLite database of products |
| `dpinstertion.py` | Helper script to create and seed the SQLite database |
| `test.py` | Local testing or experimentation script |

## Running a script

```bash
python3 <filename>.py
```
