# restful-api

Python exercises about HTTP APIs: consuming an external REST service, building an HTTP server, and exposing Flask endpoints with authentication.

## Files

| File | Description |
|------|-------------|
| `task_02_requests.py` | Fetch posts from JSONPlaceholder and save them to CSV |
| `task_03_http_server.py` | Build a simple API using `http.server` |
| `task_04_flask.py` | Create a small Flask REST API for user management |
| `task_05_basic_security.py` | Add Basic Auth and JWT-protected routes to the Flask API |

## Requirements

- Python 3
- `requests`
- `Flask`
- `flask-httpauth`
- `flask-jwt-extended`

## Run

```bash
python3 task_02_requests.py
python3 task_03_http_server.py
python3 task_04_flask.py
python3 task_05_basic_security.py
```

## Topics

- HTTP requests
- JSON and CSV processing
- REST endpoints
- Basic Auth
- JWT authentication
